One sentence pitching the worst, most useless app imaginable, for make.fun's "The Worst App Idea Ever Pitched" bounty ($2, top 8). The pitch: **MoodRing for Meetings** — it reads your boss's sighs in real time, translates each one into a 47-slide deck proving your project is fine, actually, and then emails the deck to absolutely no one, every Friday.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt` in the grader sandbox), enforcing the gate first: UTF-8 text, 1–240 characters, not only whitespace, exactly one sentence.
